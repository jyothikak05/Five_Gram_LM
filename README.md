# Five-Gram Language Model

This project implements a 5-gram (n=5) language model trained on Jane Austen's *Pride and Prejudice* from Project Gutenberg.

## Files
- `ngram_lm.py` — Python implementation of the 5-gram language model
- `pridenprejudice.txt` — Training corpus

## How to run
```bash
python3 ngram_lm.py
